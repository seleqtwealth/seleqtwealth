What it is

A Systematic Investment Plan invests a fixed amount in mutual funds every month. Because returns start earning returns of their own, small monthly steps can compound into a sizeable corpus over time.

How to use it

  1. Set how much you can invest each month.
  2. Choose an expected annual return.
  3. Pick how long you will stay invested.
  4. Set expected inflation to see the corpus in today's money.
